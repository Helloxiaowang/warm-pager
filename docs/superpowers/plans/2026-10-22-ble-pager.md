# ESP32 蓝牙翻页器实施计划

> 使用 subagent-driven-development 分工实现和复核。用户选择本轮不创建 Trellis 任务；不执行 Git 提交、分支或硬件烧录。

**目标：** 现有 ESP32-WROOM-32 类开发板通过 BLE HID 模拟鼠标，BOOT 单击下一条、双击上一条，USB 仅供电和首次烧录。

**架构：** 独立的 C++ 按键状态机负责 25 ms 消抖和 300 ms 双击窗口；Arduino 主循环读取 GPIO0，将状态机事件转换成滚轮报告。断开连接时清空手势，重连后等待松手，避免补发旧操作。负滚轮为下一条，步长默认 1，可改配置校准。

**技术栈：** PlatformIO Espressif32 6.10.0、Arduino-ESP32 2.0.17、T-vK ESP32-BLE-Mouse 0.3.1、主机 g++ 测试。

## 变更边界

项目尚无固件，新增 PlatformIO 构建配置、按键状态机、BLE 主程序、主机测试和中文使用说明。只实现一个按钮和两个翻页动作；电池电路留到实机验证后处理。工具安装在本项目虚拟环境中。

## 验收与限制

自动验收要求主机测试通过、固件编译成功。手机配对、按键实际翻页、方向和步长需用户在红米 Turbo 4 上验证，自动测试不等同于实机通过。首次烧录会替换板上原程序，本轮只准备固件和明确的烧录命令。
